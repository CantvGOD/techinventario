Este proyecto fue optimizado para ejecutarse en cualquier computadora con Windows
(incluyendo computadoras completamente limpias sin herramientas previas instaladas).

--------------------------------------------------------------------------------
1. CÓMO EJECUTAR EL PROGRAMA (UN SOLO CLIC)
--------------------------------------------------------------------------------
1. Descomprime la carpeta del proyecto en la computadora de Windows.
2. Haz doble clic en el archivo:
   👉 ejecutar.bat

¡Eso es todo! El script se encargará automáticamente de todo:
- Si la computadora NO tiene Node.js: lo descarga e instala de forma desatendida.
- Si faltan las librerías: ejecuta `npm install` automáticamente.
- Si falta compilar: compila el frontend automáticamente.
- Configura la base de datos (con MySQL si está instalado o con el motor embebido
  autónomo si no hay MySQL).
- Inicia el servidor backend y el frontend.
- Abre tu navegador web automáticamente en: http://localhost:5173/

--------------------------------------------------------------------------------
2. BASE DE DATOS Y PERSISTENCIA (SOPORTE DUAL)
--------------------------------------------------------------------------------
El sistema cuenta con un motor inteligente con soporte dual:

A) CON MYSQL / XAMPP / MARIADB:
   Si el equipo tiene MySQL (ejemplo: XAMPP en C:\xampp o MySQL Workbench),
   el script importa automáticamente el archivo `database.sql` con todas las
   tablas y datos iniciales requeridos para la defensa universitaria.

B) SIN MYSQL (INSTALACIÓN LIMPIA):
   Si la computadora de tu amigo no tiene MySQL instalado, NO TE PREOCUPES:
   El backend detecta automáticamente la ausencia de MySQL y activa el
   MOTOR EMBEBIDO LOCAL (Zero-Config), cargando la totalidad del catálogo,
   los 14 teléfonos, los usuarios, ventas, tasas BCV y gastos desde:
   `data/techinventario_database.json`.
   ¡Todas las operaciones (ventas, compras de lotes, ajustes de stock, auditoría)
   se guardan y persisten de manera idéntica!
